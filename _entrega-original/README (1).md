# Konekt Sales

Plataforma comercial de Konekt: CRM + generador de propuestas y cotizaciones con IA, en un solo HTML,
con backend seguro (la API key vive solo en el servidor).

## Correr
1. Node.js 18+ (https://nodejs.org)
2. `npm install`
3. Copia `.env.example` como `.env` y pega tu llave: `ANTHROPIC_API_KEY=sk-ant-...`
4. `npm start`
5. Abre http://localhost:3000

La API key nunca está en el HTML. Ver **HANDOFF.md** para el detalle de qué es mockup,
qué ya tiene lógica y qué falta conectar.
